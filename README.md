# Bank Transaction Analysis and Customer Behavior Insights

An end-to-end Data Science project analyzing bank transaction data to understand customer behavior, perform exploratory data analysis (EDA), and predict high-value transactions using Machine Learning.

The project includes an interactive web dashboard built with **Streamlit** to easily view insights and test the predictive model.

---

## 🚀 Features
- **Phase 1 & 2:** Comprehensive Data Cleaning and Exploratory Data Analysis.
- **Phase 3:** Machine Learning Model Development (Logistic Regression, Decision Tree, Random Forest) to predict High-Value Transactions.
- **Phase 4:** Interactive web application (Streamlit dashboard) to visualize data and predict new transactions.

---


## 🛠️ Step 1: Clone the Repository

To get started, clone this repository to your local machine:

```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
```
*(Make sure to replace `your-username` and `your-repo-name` with your actual GitHub details).*

---

## 📦 Step 2: Install Dependencies

Make sure you have Python installed (Python 3.8+ recommended). Install the required libraries using:

```bash
pip install -r requirements.txt
```

---

## 🧠 Step 3: Run the Data Pipeline & Model

Before using the dashboard, you need to clean the data and train the Machine Learning model. 
*(Ensure your `bank_transactions.csv` is placed inside the `data/` folder).*

Run the execution script:
```bash
python execute_pipeline_safe.py
```
**What this does:**
1. Cleans the original dataset and saves it.
2. Generates and saves all the graphs to the `outputs/` folder.
3. Trains the model and saves it as `final_model.pkl`.

*(Note: You can also explore the step-by-step logic inside the `notebooks/` folder using Jupyter Notebook).*

---

## 🌐 Step 4: Open the Streamlit Dashboard

Once the model and data are ready, you can launch the interactive dashboard!

1. Navigate into the `app` folder:
```bash
cd app
```

2. Run the Streamlit application:
```bash
python -m streamlit run app.py
```

3. The dashboard will automatically open in your web browser (usually at `http://localhost:8501`). 

### How to use the Dashboard:
- **Dashboard Tab:** View overall summary statistics.
- **Transaction & Customer Analysis Tabs:** Explore the interactive charts and distributions.
- **Model Prediction Tab:** Enter custom transaction details (Balance, Time, Amount) and click **Predict** to see if the Machine Learning model flags it as a High-Value Transaction!

---

## ⚠️ Important Note
The target variable `High_Value_Transaction` is a **derived target** based on transaction value thresholds created specifically for this demonstration. The original dataset does not contain real-world fraud labels.
